Notes on the data

Figures cover English-language releases only. Digital-only Magic sets, tokens, promotional sets and memorabilia are excluded, as are Magic's The List and Secret Lair, which collect cards over several years under one date. Per-year charts stop at 2025, the last complete year.

Scryfall card counts include alternative artworks, so recent Magic sets look larger partly because of those extra versions. YGOPRODeck is maintained by players, so some rarity labels needed cleaning and a few printings may be missing.

Google Trends scores are relative within each country and capped at 100; they show share of searches, not number of players. Listed prices are a September 2026 snapshot, not original retail prices. World Championship coordinates are city centres added by the author; the 2021 event was held online, so it has no host city.

Method

Raw API files were cleaned and aggregated with a Python script, scripts/prepare_data.py, which writes every CSV in the data folder. Each chart is a separate Vega-Lite specification in the js folder, embedded with vega-embed and published on GitHub Pages.

Page template and interaction patterns adapted from the FIT3179 studio examples.
